# The Leamington Drop

One-page site for [@leamingtondrop](https://www.instagram.com/leamingtondrop/): all the best shops, bars and restaurants dropping in Royal Leamington Spa.

## What's here

- `index.html` is the whole site in a single file: styles, scripts and images are all built in, so there's nothing to install or build.
- Fonts load from Google Fonts (Bricolage Grotesque).
- Map data © OpenStreetMap contributors (ODbL).

## Run it locally

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy

Any static host works. On Vercel, import this repo and deploy with the default settings (no framework, no build command).
